# Sentiment Analysis

Projeto de análise de sentimento com tweets em português usando modelos clássicos de machine learning.

## O que foi feito
- leitura do dataset local
- separação entre texto e classe
- vetorização com `CountVectorizer`
- treino de 3 modelos
- comparação com 3 proporções de treino/teste
- avaliação com acurácia e matriz de confusão
- sanity check simples no final

## Modelos usados
- Multinomial Naive Bayes
- Decision Tree
- SVC

## Estrutura
- `data/`: dataset usado no projeto
- `notebooks/`: notebook principal do projeto

## Observação
O notebook foi reorganizado a partir de uma versão de estudo anterior, mantendo a lógica principal do fluxo.
